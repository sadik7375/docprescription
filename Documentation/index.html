Complete cPanel / Shared Hosting Guide

Step-by-Step cPanel Deployment Guide

Follow this straightforward visual tutorial to upload, configure, and install Doc Helper AI on standard cPanel hosting (Namecheap, Hostinger, SiteGround, cPanel / WHM, LiteSpeed, etc.) in under 5 minutes.

1

Create MySQL Database & User in cPanel

cPanel > MySQL Database Wizard

Log into your cPanel account, search for "MySQL Database Wizard", and follow these 3 quick sub-steps:

  • Step 1.1 (Create Database): Enter a database name (e.g. youruser_docai) and click Next Step.
  • Step 1.2 (Create User): Enter a username and generate a strong secure password. (Make sure to copy the database name, username, and password into a temporary text file for the installer).
  • Step 1.3 (Set Privileges): Check the box "ALL PRIVILEGES" and click Make Changes.
2

Configure PHP Version (PHP 8.2 or 8.3) & Extensions

cPanel > Select PHP Version / MultiPHP Manager

Doc Helper AI requires PHP 8.2 or PHP 8.3.

Required PHP Extensions:

bcmath, curl, fileinfo, mbstring, openssl, pdo_mysql, xml, zip, gd

Recommended PHP Limits:

memory_limit = 512M | max_execution_time = 300 | upload_max_filesize = 64M

3

Upload the Project ZIP File to cPanel File Manager

cPanel > File Manager

Open File Manager in cPanel:

  1. Navigate to the folder of your website (e.g. public_html or your subdomain folder).
  2. Click the top "Upload" button.
  3. Select the downloaded doc-helper-ai.zip archive and wait until the upload progress bar turns 100% Green.
4

Extract the ZIP Archive

File Manager > Extract

Back in File Manager:

  • Right-click on doc-helper-ai.zip and select "Extract".
  • Confirm the destination path and click "Extract File(s)".
  • Click the "Settings" gear icon at the top right of File Manager and ensure "Show Hidden Files (dotfiles like .env, .htaccess)" is checked.
5

Open Web Browser & Run Installation Wizard

Web Browser

Open your web browser (Chrome, Firefox, Safari, Edge) and navigate to:

https://yourdomain.com/install

The visual wizard will guide you through:

  • Server Requirements & PHP Extensions Check
  • Folder Permissions Auto-Verification
  • Database Name, User & Password Configuration
  • Master Super Admin Account Setup
7

Setup Automatic Background Cron Job in cPanel

cPanel > Cron Jobs

To handle appointment reminders, subscription expiration notifications, and background AI tasks automatically, configure a 1-minute cron job in cPanel:

1. Select Interval:

In the Common Settings dropdown, select "Once Per Minute (* * * * *)".

2. Command to Run:
/usr/local/bin/php /home/USERNAME/public_html/artisan schedule:run >> /dev/null 2>&1

(Replace USERNAME with your actual cPanel username and adjust the directory path to match your installation).

Doc Helper AI includes a built-in graphical installation wizard that configures database tables, environment variables, and super admin account with zero command line knowledge needed.

Wizard Steps Walkthrough

Step 3.1: Welcome & Overview

installer/welcome

Introduces the guided setup process and checks basic system readiness. Click "Check Requirements" to begin.

Step 3.2: Server Requirements Verification

installer/requirements

Checks PHP version (>= 8.2) and all required extensions. All items must show a green checkmark before proceeding.

Step 3.3: Directory & File Permissions

installer/permissions

Verifies that storage/, bootstrap/cache/, and .env are writable (permission 775 or 755).

Step 3.4: App URL & Database Configuration

installer/environment

Set your Application Name (e.g. Doc Helper AI), exact App URL (e.g. https://your-domain.com), and MySQL database host, username, password, and database name.

Step 3.5: MySQL Database Connection & Migration

installer/database

Automatically runs database migrations, builds the clinical database schema, and seeds essential clinical and drug libraries.

Step 3.6: Super Admin Account Creation

installer/admin

Create your master Super Admin account with Full Root Access (Name, Email, and secure Password).

Step 3.7: Complete & Launch

installer/finish

Congratulations! Installation is finalized, configuration cached, and installer locked for security. You can now log into your Super Admin Portal.

Developers & VPS

Manual CLI / VPS / Localhost Installation

For Linux VPS (Ubuntu / Debian), Laragon, XAMPP, Docker, or local development environments.

Run the following commands in order inside your terminal:

1. Clone / Extract & Install Composer Dependencies: 
cd /path/to/doc-helper-ai
composer install --no-dev --optimize-autoloader
2. Setup Environment File: 
cp .env.example .env
php artisan key:generate
3. Run Database Migrations & Initial Seeds: 
php artisan migrate:fresh --seed
4. Create Storage Symlink & Build Frontend: 
php artisan storage:link
npm install
npm run build
5. Optimize Application & Clear Caches: 
php artisan optimize:clear
php artisan optimize
Automation

Cron Job & Queue Automation Setup

The cron job is required for automatic subscription expiration checks, automated daily appointment reminders (SMS/Email), and invoice generation.

cPanel Cron Job Setup:

In cPanel, search for Cron Jobs and add a new cron job set to run Every Minute (* * * * *): 

* * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1

Supervisor Queue Worker (VPS):

[program:doc-helper-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/doc-helper-ai/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/doc-helper-ai/storage/logs/worker.log

Troubleshooting

Frequently Asked Questions & Troubleshooting

Getting 500 Internal Server Error after uploading?

Ensure your server PHP version is at least 8.2 and the following folder permissions are writable: chmod -R 775 storage bootstrap/cache. Also verify that .env exists and APP_KEY is generated.

Routes give 404 Not Found (Only home page loads)?

Make sure Apache mod_rewrite is enabled and the default public/.htaccess file is present. On Nginx, ensure your server block contains try_files $uri $uri/ /index.php?$query_string;.

Uploaded logos and photos are not showing?

Run php artisan storage:link in your project directory to link public storage.
